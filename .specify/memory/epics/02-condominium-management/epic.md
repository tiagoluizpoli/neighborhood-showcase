## About this Epic

End-to-end condominium lifecycle: Síndico creation with document proof, resident self-service joining, and admin/moderator approval workflows.

## Context

Síndicos create condos with proof documents (uploaded to S3). Residents search and request to join approved condos. Admins approve/reject condo registrations. Moderators approve/reject resident requests.
