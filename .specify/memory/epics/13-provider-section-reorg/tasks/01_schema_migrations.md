## What to Build

Add the 5 new `provider_profile` columns (`companyName`, `tradeName`, `logoUrl`, `bannerUrl`, `publicDescription`) and the 2 new `user` columns (`language`, `theme`) via Drizzle. Generate the migration with `bun run db:generate`; do NOT hand-write SQL. Apply it via `bun run db:migrate`. This task produces zero application code — only schema. It is the dependency root for tasks 02–10.

## Context

Module 25 of `/PRD.md` (merged 2026-06-10), §"Schema changes". `agents.local.md` §8 governs migration discipline (additive, no DROP, no RENAME; generated by `bun run db:generate`, applied via `bun run db:migrate`). `packages/db/src/schema/showcase.ts` owns the `provider_profile` table; `packages/db/src/schema/auth.ts` owns the `user` table.
